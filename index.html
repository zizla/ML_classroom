CSV 형식 / 데이터 처리

헤더: x1,x2,target. 분류 target은 0 또는 1, 회귀는 숫자, 비지도는 생략 가능합니다. 40~180개 행을 사용합니다. CSV의 두 특성은 전체 표본의 최댓값·최솟값으로 −0.9~0.9에 선형 변환됩니다. 교육용 시각화 전처리이며 엄밀한 홀드아웃 평가 파이프라인은 아닙니다. 회귀 target도 같은 방식으로 변환됩니다. 결측·비수치 행은 거부합니다.

실험 저장은 데이터·설정만 저장하며 학습된 가중치나 Orange3 모형을 저장하지 않습니다.

교육용 합성 데이터입니다. 성능은 현재 데이터 분할에 한정됩니다.
